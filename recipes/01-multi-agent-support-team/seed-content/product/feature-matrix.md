## When to upgrade

Upgrade to Business if you:

- Need more than 3 team members
- Consistently hit the 10,000 request / month cap on Starter
- Need a documented uptime SLA or email support
- Need a custom domain for your API endpoints

Upgrade to Enterprise if you:

- Require SSO or SCIM for security / compliance reasons
- Need multi-region deployments for data residency
- Require HIPAA or a custom security review
- Have a negotiable contract with procurement
